# ✦ OmniChat — Todas as IAs em um só lugar

Chat unificado que conecta Claude, GPT, Gemini, Groq e OpenRouter numa única interface bonita, com histórico de conversas.

## 🚀 Como usar

### 1. Instale as dependências
```bash
npm install
```

### 2. Configure suas chaves de API
```bash
cp .env.example .env
# Edite o .env com suas chaves
```

### 3. Inicie o servidor
```bash
bash start.sh
# ou
node server.js
```

### 4. Abra no navegador
```
http://localhost:3000
```
